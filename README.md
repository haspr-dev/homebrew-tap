## 🛠️ Usage

To install `go-pbolt-cli` via Homebrew:

```bash
brew tap pbolt-dev/tap
brew install pbolt
```

For more documentation and features, see [github.com/pbolt-dev/go-pbolt-cli](https://github.com/pbolt-dev/go-pbolt-cli).
