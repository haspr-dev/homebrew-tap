## 🛠️ Usage

To install `haspr` via Homebrew:

```bash
brew tap haspr-dev/tap
brew install haspr
```

For more documentation and features, see [github.com/haspr-dev/go-haspr-cli](https://github.com/haspr-dev/go-haspr-cli).
